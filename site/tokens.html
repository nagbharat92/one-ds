Tokens

Every non-color token: spacing, shape, sizing, depth, motion, opacity, stacking, and component geometry. Values on this page are written by scripts/build-tokens.mjs, and a token with no row here fails the build.

Rhythm

The public spacing API. Every gap comes from one of these seven rungs, chosen by the relationship between the two things being separated, never by a distance.

Gap between siblings
TokenValueUse between
4pxParts fused into one object, such as an icon and its label
8pxA thing and its own annotation, such as a heading and its description
12pxRepeated equals in one set, such as chips or list rows
16pxDistinct siblings in one region, such as a table and the note beside it
24pxA header and the content it introduces
40pxPage-level blocks
64pxThe page's own top and bottom edge

Inset

Padding for a surface. A container's inset always exceeds the gap between its children, so nesting can never invert.

Padding inside a surface
TokenValueUse on
12pxA dense surface, such as a table cell or menu item
16pxA card, panel, or popover
24pxA dialog or hero

Elevation and blur

Each elevation is an ambient shadow plus a key shadow, and resolves its opacity through the active color-scheme. Both schemes are shown together because a shadow tuned for light paper disappears on dark.
