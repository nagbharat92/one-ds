Themes

Four numbers in tokens/theme.json generate every color token. Nothing else changes between themes.

Theme file

Edit the four parameters, rebuild, done.

tokens/theme.json

{
  "accentHue": 45,
  "groundOffset": 45,
  "groundLightness": 0.981,
  "chromaScale": 1.0
}

Rebuild

node scripts/build-tokens.mjs
Theme parameters
ParameterControlsRange
accentHueThe hue everything is built from: the accent, the links, and the ink.0 to 360
groundOffsetHow far the page color sits from the accent color.-180 to 180
groundLightnessHow light the page is, from near white to a color in its own right.0.88 to 0.985
chromaScaleHow much color every token carries, from plain grey to vivid.0 to 1.5

What changes

The parameters move color. Nothing else.

Generated from the parameters

  • Neutral surfaces, backgrounds, strokes, foregrounds
  • Brand fills, strokes, foregrounds
  • Focus ring
  • Expression hues
  • Hover and pressed states

Fixed in every theme

  • Status: danger, warning, success
  • Fixed black and white
  • Spacing, radius, stroke widths
  • Typography
  • Control and icon sizes
  • Motion, opacity, layers
  • Component geometry

Light and dark

Every token is one light-dark() declaration. Without an attribute the page follows the system preference; data-theme forces a scheme.

<html data-theme="light">
<html data-theme="dark">
