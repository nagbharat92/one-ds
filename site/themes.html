Themes

OneDS themes change semantic meaning at the document root while preserving a shared reference scale and component geometry.

Theme mechanism

Set data-oneds-theme on the document root to choose a mode explicitly.

<html lang="en" data-oneds-theme="light">
<html lang="en" data-oneds-theme="dark">

What switches

Semantic RGB channels, semantic colors, shadow alpha, elevations, backdrop alpha, and color-scheme resolve to the selected light or dark values.

What stays fixed

Reference palettes, spacing, typography, radii, control sizes, icon sizes, motion, opacity, layers, and component geometry do not change between themes.

When the attribute is absent, prefers-color-scheme: dark selects dark semantic values for users with a dark system preference. An explicit attribute takes precedence.

The same components in both themes

The markup and component classes are identical. Only the enclosing theme attribute changes.

Alpha layering

Interaction states are translucent layers built from the active semantic ink or accent channel.

Surface
Ink hover layer
Ink active layer
Accent selected layer

Hover and active colors are not independent opaque swatches. They apply a small amount of semantic ink over the surface beneath them, preserving the relationship between the surface and the active theme.

Selected colors use the semantic accent channel in the same way. This keeps state emphasis coherent when the base surface changes and avoids maintaining separate opaque state palettes for every theme.

Adding a new color

Add color by role, not by appearance.

  1. Add a source RGB channel to both reference theme palettes.
  2. Alias those channels in both semantic RGB scopes using one shared semantic name.
  3. Build opaque or alpha semantic colors from that channel according to their role.
  4. Use the semantic variable in components; do not point components at light or dark reference colors directly.
  5. Regenerate tokens.css and run the checker.

A new state color should normally remain an alpha layer over semantic ink or accent. Add separate light and dark opaque values only when compositing cannot express the intended role.
