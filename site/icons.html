Icons

Interface glyphs come from Fluent System Icons. Site marks come from Google's favicon service. OneDS ships neither set — it tells you how to address the exact asset you need.

Get any icon

Every Fluent icon is addressable by name, grid size, and style, so there is no OneDS icon set to choose from. Browse the icon catalog, the source assets, or the svg-icons package.

Icon prompt

Add a Fluent System Icon for this concept.

- Find the closest icon by meaning in https://github.com/microsoft/fluentui-system-icons/tree/main/assets. Never draw a replacement, and never stand in an emoji, an arrow character, or a letter.
- Use the regular style. Switch to filled only for a selected, current, or active item, or for a status glyph whose meaning is the point.
- Decide the rendered size first, then fetch the asset drawn on that grid: 12, 16, 20, 24, 28, or 32. Never scale a larger grid down.
- Inline the SVG in the markup. Keep the viewBox, set fill="currentColor" on every path, and delete the width, height, and any hardcoded fill or color attributes.
- Size it in CSS with an --oneds-reference-icon-size-* token. Never put width or height on the svg element.
- Add aria-hidden="true" when a text label is already present. If the icon is the only content of a control, give the control an aria-label naming the action.
ic_fluent_{name}_{size}_{style}.svg

Regular or filled

Weight marks state, not emphasis. Regular is the default everywhere.

Style by situation
SituationStyle
Resting, decorative, or supporting a labelregular
Selected tab, current page, active togglefilled
Status glyph carrying the message: error, success, warningfilled
Hover or focusregular. Those states are carried by color and background, never by weight.
Two icons in one control groupOne style throughout. Never mix regular and filled side by side.

Size

Size is decided by the surface the icon sits on, never by taste. Each OneDS icon size is also a Fluent grid, so the token value and the asset you fetch are the same number.

Size by surface
SurfaceRuleResult
Inline with textMatch the band of the text it rides with.12px text takes xs, 14px and 16px take sm, 20px takes md, 24px and up take lg
Inside a square control or tileHalf the container, snapped to the grid.32px control takes sm, 40px tile takes md, 48px tile takes lg
Focal, leading a centred blockNo container to relate to, so it takes the top of the ramp.2xl
Icon size tokens and their Fluent grid
TokenRendersFetch gridWhere it lands
--oneds-reference-icon-size-xs12px12Inline with 12px metadata
--oneds-reference-icon-size-sm16px16Buttons and menu items at 32px. The default.
--oneds-reference-icon-size-md20px20Composer actions and status tiles at 40px
--oneds-reference-icon-size-lg24px24Controls and tiles at 48px
--oneds-reference-icon-size-xl28px28Feature rows and dialog leads
--oneds-reference-icon-size-2xl32px32Empty states and other focal glyphs

Fluent redraws every grid at its own stroke weight, so a 24 asset rendered at 16px comes out hairline. A component that owns an icon slot sizes the glyph from its own token, never from a class the page adds.

Markup

An icon inherits its color from text and takes its size from a token, so one asset works in every theme and at every scale.

<svg class="icon" viewBox="0 0 16 16" aria-hidden="true">
  <path d="M2.5 4.5h11…" fill="currentColor"/>
</svg>

.icon {
  width: var(--oneds-reference-icon-size-sm);
  height: var(--oneds-reference-icon-size-sm);
}
Markup rules
RuleDetail
ColorPut fill="currentColor" on every path. To recolor, set color on the icon or an ancestor from a foreground token. Never write a color token onto the <svg>.
SizeWidth and height come from an icon size token in CSS. Never put width or height attributes on the element.
Decorativearia-hidden="true" whenever a text label is already present.
Icon-only controlaria-label naming the action, placed on the control, not on the <svg>.
StatusKeep the meaning in text as well. An icon never carries a status alone.
Inline, never referenced<use href="sprite.svg#id"> needs a second file, and OneDS output HTML may not reference external files. This documentation site uses a sprite; product markup inlines the path.

Favicons

When an interface lists websites, fetch each site mark from Google's favicon service instead of storing images. Request at twice the rendered size and draw it into a tokenized box.

Favicon rules
RuleDetail
Only powers of twosz accepts 16, 32, 64, 128, and 256, and anything else is snapped. Take the first value at or above twice the rendered size so the mark stays sharp on a 2x display.
Encode the hostBuild the URL with an encoded host. Never concatenate raw user input into it.
Never proxy openlyIf a server fetches on the client's behalf, allowlist the hosts it may resolve. An open fetcher is a server-side request forgery hole.
Always fall backThe endpoint is unofficial and best effort. On error show the Fluent globe glyph on --oneds-color-background-neutral-subtle rather than a broken image. The faviconV2 form can return a generated mark instead of failing.
Load quietlyloading="lazy", decoding="async", and referrerpolicy="no-referrer". Sizing the box in CSS keeps the row from shifting while the image arrives.
Empty altThe site name sits beside the mark, so alt="" avoids announcing it twice.
Public hosts onlyEvery request tells Google which site the user is looking at. Do not send internal or private hostnames.
