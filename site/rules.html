Rules

The OneDS generation contract in plain language, with a small violation and correction for each source rule.

Route work first

Decide whether a shared component already owns the pattern before writing interface code.

Read the manifest before writing UI

The manifest is the source of truth for available and planned component roles.

Violation
# Start writing a card from memory
Correction
cat oneds/MANIFEST.md
# Then choose the matching component

Keep unmatched interface work local

If no manifest component matches, build the pattern in src/_local/ and identify what it was for.

Violation
src/sidebar.css
Correction
src/_local/sidebar.css
/* ONEDS-CANDIDATE: sidebar, project navigation. */

Component integrity

A shared component is copied as one owned implementation, not used as inspiration for a local fork.

Copy a matching component verbatim

Use the files in oneds/components/<name>/ without altering the component implementation.

Violation
<div class="my-card">...</div>
Correction
<article class="card">...</article>

Update the manifest with a new component

Creating a component directory and marking its manifest status built are one change.

Violation
components/stat/
MANIFEST.md: stat | not built
Correction
components/stat/
MANIFEST.md: stat | built

Do not rewrite or fork a match

Application code must not create a parallel version of an existing library component.

Violation
.project-button {
  /* a second button implementation */
}
Correction
<button class="button" type="button">Save</button>

Token discipline

Themeable design values come from the generated OneDS token vocabulary.

Use tokens for color, spacing, and size

Every authored visual value in those categories must resolve through a defined --oneds- variable.

Violation
.panel {
  padding: 16px;
  color: #333;
}
Correction
.panel {
  padding: var(--oneds-inset-default);
  color: var(--oneds-color-foreground-neutral-primary);
}

Never invent a visual value

If no defined token expresses the need, stop and report the gap instead of making up a value.

Violation
.panel {
  gap: 18px;
}
Correction
# Report: no token exists for the required gap.
# Do not author the declaration yet.

Edit token source, not generated CSS

Color theme changes go in tokens/theme.json; status colors and every non-color token go in tokens/oneds.tokens.json. Rebuild tokens.css either way.

Violation
# Hand-edit tokens.css
Correction
# Edit tokens/theme.json or tokens/oneds.tokens.json
node scripts/build-tokens.mjs

Write layout keywords literally

Custom properties are for themeable values, not CSS grammar such as display or alignment modes.

Violation
.layout {
  display: var(--oneds-display-grid);
}
Correction
.layout {
  display: grid;
}

Icons and marks

Glyphs are fetched from Fluent System Icons and site marks from Google's favicon service, so neither is drawn by hand or stored in the project. Full guidance is on the icons page.

Fetch the grid you render at

Every icon size token is a Fluent grid, and Fluent redraws each grid at its own stroke weight.

Violation
ic_fluent_copy_24_regular.svg
/* rendered at 16px */
Correction
ic_fluent_copy_16_regular.svg
/* --oneds-reference-icon-size-sm */

Inline the icon and let it inherit

Colour comes from the surrounding text and size comes from a token, so one asset serves every theme.

Violation
<svg width="16" height="16">
  <use href="sprite.svg#copy"></use>
</svg>
Correction
<svg class="icon" viewBox="0 0 16 16" aria-hidden="true">
  <path d="…" fill="currentColor"/>
</svg>

Size the icon from its surface

Inline, match the text band. Inside a square control or tile, take half the container. Leading a centred block, take the top of the ramp.

Violation
/* 40px danger tile */
.tile svg { width: 16px; }
Correction
.dialog__icon svg {
  width: var(--oneds-component-dialog-icon-size);
}

A component owns its icon slot

If a component has an icon, its own CSS sizes it. Leaving the size to whatever class the page adds is how a focal glyph ends up at 16px.

Violation
.empty-state__icon {
  color: var(--oneds-color-foreground-neutral-tertiary);
}
Correction
.empty-state__icon {
  width: var(--oneds-component-empty-state-icon-size);
  height: var(--oneds-component-empty-state-icon-size);
  color: var(--oneds-color-foreground-neutral-tertiary);
}

Reserve filled for state

Weight marks a selected, current, or active item, or a status glyph. It is never a way to add emphasis.

Violation
ic_fluent_home_20_filled.svg
/* resting nav item */
Correction
ic_fluent_home_20_regular.svg
/* filled only when current */

Name the control, hide the decoration

An icon supports a label; it never becomes the accessible name by itself.

Violation
<button class="button button--icon">
  <svg>…</svg>
</button>
Correction
<button class="button button--icon" aria-label="Copy">
  <svg aria-hidden="true">…</svg>
</button>

Request a favicon at twice the rendered size

The service only serves powers of two, so a mark rendered at 20px is requested at 64 and drawn into the favicon tokens.

Violation
<img src="…/s2/favicons?domain=example.com"
     width="20" height="20">
Correction
<img class="favicon" alt="" loading="lazy"
     referrerpolicy="no-referrer"
     src="…/s2/favicons?domain=example.com&sz=64">

Output structure

Generated consuming-project HTML is self-contained and preserves the required semantic wrappers.

Put every table inside a card

The required rule states that tables always need the shared bounded surface.

Violation
<table>...</table>
Correction
<div class="card">
  <table>...</table>
</div>

Inline CSS in generated output

For consuming-project output, copy token and component CSS into a <style> block.

Violation
<link rel="stylesheet" href="oneds/tokens.css">
Correction
<style>
  /* copied tokens.css and component CSS */
</style>

This local reference catalog intentionally uses real stylesheet links because its build brief explicitly requires linked library sources.

Do not include external file references in generated output

Generated consuming-project HTML must not depend on stylesheet links, script references, or CSS imports. A remote image fetched at request time, such as a favicon, is not covered by this rule.

Violation
@import "oneds/components/button/button.css";
Correction
<style>
  /* verbatim component CSS */
</style>

Never present a table outside a card

The forbidden form of the table rule repeats the same boundary explicitly: a bare table is invalid.

Violation
<main>
  <table>...</table>
</main>
Correction
<main>
  <div class="card">
    <table>...</table>
  </div>
</main>
