Data table

Presents structured records for scanning and comparison across columns. Grey fills and semibold, secondary-grey labels name the structure — a caption titles the table, the filled header row labels the columns, and a row header identifies each record — leaving the data cells in primary ink on the plain surface. Each body row is a backplate with a full interaction ramp — rest, hover, pressed, and disabled — and a selected row runs the same ramp on the filled band. An optional footer summarises the columns above it, and the data-table__scroll wrapper lets a wide table scroll sideways rather than break the layout.
