Typography

One variable family and two role ramps. Every role pairs a size, a line height, and a letter spacing — take all three. Each specimen below is the role name set in its own role.

Families

Base carries every role. Editorial and code are slots a project can override.

FamilyUsed forStack
baseEvery interface and content role"Segoe UI Variable", "Segoe UI", -apple-system, "Helvetica Neue", sans-serif
editorialLong-form serif material"Iowan Old Style", "Palatino Linotype", Palatino, Georgia, "Times New Roman", serif
codeSource listings and terminal output"Cascadia Code", "SFMono-Regular", Menlo, Consolas, "Liberation Mono", monospace

--oneds-reference-font-family-<name> · Segoe UI Variable ships as one WOFF2 Latin subset, weight axis 300–700, optical size axis 5–36 left automatic, swap display.

Measure

Body copy is capped so a line never outruns the eye. Specimens, tables, and component examples are exempt because they are scanned rather than read.
